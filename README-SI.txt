LIFE'S GOOD KITCHEN — WEBSITE DEMO
=================================

Files:
- index.html : Home page, gallery, restaurant information, Google Maps and review links.
- menu.html  : Separate food menu page with visible prices, category filters, search and basket.
- style.css  : Responsive styling.
- script.js  : Menu filtering, basket and WhatsApp order-request behaviour.
- assets/    : Restaurant images supplied in the PDF, enlarged 4x with image sharpening.

How to preview:
1. Extract the ZIP file.
2. Open index.html in Firefox or Chrome.
3. Click “Menu & Prices” to open menu.html.

Ordering:
The basket creates a WhatsApp order request to the listed restaurant number. It is a demo ordering flow, not a payment gateway or restaurant-connected ordering backend. The restaurant must confirm availability, delivery and final prices.

Menu accuracy:
The displayed food names/prices were collected from public menu listings and need confirmation with the restaurant. Pizza has been removed from the menu because it was not confirmed as an added menu item. Only categories containing listed items are shown. Repeated food names are deduplicated.

Images:
Images from the supplied PDF have been upscaled 4x and sharpened. Upscaling improves display size, but cannot restore details that were not present in the original image. Some images are illustrative and may not depict the exact menu item.

This is an independent demo website concept and is not an official restaurant website.
